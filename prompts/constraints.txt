========================================
INTERR.IO CONSTRAINTS & INVARIANTS v2.0
========================================

Цей файл містить незмінні правила, які ЗАВЖДИ повинні виконуватися при генерації.


========================================
КРИТИЧНІ ІНВАРІАНТИ (MUST FOLLOW)
========================================

## 1. ГЕОМЕТРІЯ КІМНАТИ (Room Geometry Preservation)
✓ ЗАВЖДИ зберігай точні розміри та форму кімнати з вхідного зображення
✓ НЕ додавай нові стіни, вікна або двері
✓ НЕ видаляй існуючі архітектурні елементи
✓ Зберігай висоту стелі та площу підлоги
✓ Поважай розташування та розмір вікон

## 2. МАСШТАБ ТА ПРОПОРЦІЇ (Scale & Proportions)
✓ Використовуй стандартні розміри меблів:
  - Диван: 180-220 см ширина, 80-90 см глибина
  - Ліжко двоспальне: 160-200 см ширина
  - Обідній стіл: 75-76 см висота
  - Стілець: 45-50 см висота сидіння
✓ Залишай мінімум 60 см для проходів
✓ Дотримуйся ергономічних стандартів

## 3. ФОТОРЕАЛІЗМ (Photorealism Requirements)
✓ Використовуй фізично точне освітлення
✓ Додавай м'які тіні та ambient occlusion
✓ Включай дрібні недосконалості (легке зношення, природні варіації)
✓ Використовуй реалістичні матеріали з правильним scaling
✓ Уникай AI артефактів та спотворень

## 4. ФУНКЦІОНАЛЬНІСТЬ (Functional Design)
✓ Розміщуй меблі логічно для призначення кімнати
✓ Забезпечуй достатній простір для руху
✓ Враховуй ергономіку та зручність використання
✓ НЕ перевантажуй простір декором


========================================
ОБМЕЖЕННЯ ЗА БЮДЖЕТОМ
========================================

## BUDGET-FRIENDLY (Бюджетний)
✓ Дозволено: IKEA-стиль меблі, ламінат, прості освітлювальні прилади
✓ Заборонено: мармур, дизайнерські меблі, дорогі матеріали
✓ Фокус: функціональність, простота, сучасний вигляд

## MID-RANGE (Середній)
✓ Дозволено: якісні матеріали, дерев'яна підлога, стильні меблі
✓ Заборонено: екстремальна розкіш, екзотичні матеріали
✓ Фокус: баланс між якістю та ціною

## LUXURY (Преміум)
✓ Дозволено: високоякісні матеріали, custom меблі, дизайнерське освітлення
✓ Заборонено: дешеві матеріали, пластикові поверхні
✓ Фокус: ексклюзивність, найкраща якість


========================================
СТАНДАРТИ ОСВІТЛЕННЯ
========================================

✓ Основне освітлення: люстра або стельові світильники
✓ Додаткове: настінні бра, торшери, настільні лампи
✓ Акцентне: підсвітка ніш, полиць, картин
✓ Природне: використовуй існуючі вікна
✓ Температура світла:
  - Спальня: 2700-3000K (тепле)
  - Кухня/Ванна: 4000-5000K (нейтральне)
  - Вітальня: 3000-3500K (тепле-нейтральне)


========================================
ПРАВИЛА ДЛЯ РІЗНИХ ТИПІВ КІМНАТ
========================================

## LIVING ROOM (Вітальня)
✓ Основа: диван + журнальний столик + TV/медіа зона або камін
✓ Додатково: крісла, полиці, рослини
✓ Зони: зона відпочинку, можливо зона читання
✓ НЕ включай: ліжко, кухонні прилади

## BEDROOM (Спальня)
✓ Основа: ліжко + прикроватні тумбочки + шафа/гардероб
✓ Додатково: туалетний столик, крісло, комод
✓ Освітлення: центральне + прикроватні лампи
✓ НЕ включай: кухонні прилади, обідній стіл

## KITCHEN (Кухня)
✓ Основа: кухонний гарнітур + робоча поверхня + побутова техніка
✓ Меблі: обідній стіл або bar стійка
✓ Матеріали: легкі в очищенні поверхні
✓ НЕ включай: м'які меблі, килими, спальні меблі

## BATHROOM (Ванна кімната)
✓ Основа: раковина + унітаз + душ/ванна
✓ Зберігання: шафки, полиці
✓ Матеріали: вологостійкі (плитка, камінь)
✓ НЕ включай: м'які меблі, килими, кухонні прилади


========================================

========================================

□ Освітлення натуральне та логічне
□ Матеріали відповідають бюджету
□ Стиль консистентний по всій кімнаті
□ Немає AI артефактів чи спотворень
□ Дизайн функціональний та практичний
□ Включено тільки необхідні елементи для даного типу кімнати
□ Відповідає запиту
