## Огляд

Я створив систему промптів для генерації фотореалістичних концептів дизайну інтер'єру на основі фото порожньої кімнати та текстового запиту.

## Мій Підхід

Моя система побудована на принципах:
- **Простота**: Зрозумілі шаблони, які легко підтримувати
- **Контрольованість**: Чіткі параметри для стилю, матеріалів, освітлення
- **Надійність**: Збереження геометрії кімнати, уникнення нереалістичних об'єктів
- **Гнучкість**: Працює з різними AI backend'ами (OpenAI, Gemini, Stable Diffusion)

## Як Використовувати

### 1. Заповніть змінні в шаблоні

У файлі `prompts/main_template.txt` замініть плейсхолдери:

- `{ROOM_TYPE}` - тип кімнати (living room, bedroom, kitchen, bathroom)
- `{STYLE}` - стиль (modern, scandinavian, industrial, minimalist)
- `{MOOD}` - настрій (cozy, bright, elegant, calm)
- `{BUDGET_TIER}` - бюджет (budget-friendly, mid-range, luxury)
- `{COLOR_PALETTE}` - кольорова палітра (warm neutrals, cool tones, earthy)
- `{SPECIAL_REQUIREMENTS}` - додаткові вимоги (must include reading corner, pet-friendly)

### 2. Використайте негативний промпт

Файл `prompts/negative_template.txt` містить речі, яких треба уникати. Використовуйте його разом з основним промптом.

### 3. Згенеруйте Результат

Система видає:
- **Фінальний промпт** готовий для генератора зображень
- **Негативний промпт** для уникнення небажаних елементів
- **Параметри генерації** (strength, steps, variants)
- **Design Intent Summary** короткий опис концепції
- **Constraints Checklist** список застосованих обмежень

## Що моя система виводить (Output Contract)

### Я зроби так, щоб система виводила:

1. **Assembled Main Prompt**
   - Повністю зібраний промпт з усіма змінними
   - Готовий до використання з будь-яким генератором

2. **Negative Prompt**
   - Список небажаних елементів
   - Запобігає типовим помилкам та галюцинаціям

3. **Generation Parameters**
   ```
   - Strength: 0.7-0.9
   - Steps: 30-50
   - Number of variants: 2-4
   - Seed: random or fixed
   ```

4. **Design Intent Summary**
   - Одне речення про основну ідею дизайну
   - Допомагає зрозуміти, що повинно вийти

5. **Applied Constraints Checklist**
   - ✓ Збережено геометрію кімнати (стіни, вікна, двері)
   - ✓ Застосовано бюджетні обмеження
   - ✓ Відповідає вибраному стилю
   - ✓ Використано реалістичні матеріали

## Чому я обрав саме такий формат?

- **Для UI**: Design Intent можна показати користувачу як підказку
- **Для Дебагу**: Checklist допомагає мені зрозуміти, що пішло не так
- **Для Reproducibility**: Фіксовані параметри дозволяють повторити результат
- **Для Ітерацій**: Template-based підхід легко оновлювати, якщо я щось змінюю
