## Design Intent Summary

"Затишний куточок для читання біля вікна з комфортним кріслом, простими полицями для книг та м'яким освітленням, створений з доступних матеріалів для максимального комфорту при мінімальних витратах."

## Applied Constraints Checklist

- ✅ Збережено розташування вікна (критично для reading nook)
- ✅ Бюджетні меблі та матеріали
- ✅ Включено крісло, полиці, освітлення для читання
- ✅ Затишна, тепла атмосфера
- ✅ Функціональна зона для читання

## Очікуваний Результат

**Що має вийти:**
- Комфортне крісло біля вікна (можливо м'яке крісло з IKEA типу STRANDMON)
- Невелика книжкова полиця або стелаж (IKEA BILLY, або проста дерев'яна)
- Торшер або настільна лампа для читання (тепле світло)
- М'який килимок під кріслом
- Можливо невеликий side table для чашки чаю
- Подушка або плед на кріслі для затишку
- Книги на полицях (різних кольорів корінців)
- Тепле природне світло з вікна

**Кольори:**
- Бежеві, кремові, теплі сірі тони
- Натуральне дерево
- М'які текстури (вовна, льон, бавовна)

## Що Спрацювало / Що Покращити

### ✅ Спрацювало:
- "Reading corner by the window" чітко позиціонує зону
- "Good lighting for reading" забезпечує наявність лампи
- Budget-friendly обмежує дорогі меблі
- Warm and inviting створює потрібний настрій

### 🔧 Можна покращити:
- Якщо крісло недостатньо комфортне: "plush armchair with cushions"
- Для більшої затишності: "soft throw blanket, warm ambient lighting"
- Якщо недостатньо книг: "full bookshelves, well-stocked with books"

## Примітки

Цей приклад показує як система працює з **конкретною зоною** всередині кімнати, а не повним редизайном. Ключові моменти:

1. **Вікно має зберегтися** - це критично для reading nook, тому CRITICAL інструкція про geometry preservation дуже важлива

2. **Special requirements деталізовані** - не просто "reading corner", а з конкретними елементами (chair, shelves, lighting)

3. **Budget-friendly підхід** - показує що затишок не вимагає великих витрат, фокус на функціональності та текстурах

4. **Масштаб** - важливо щоб крісло не було гігантським, а полиця не займала всю стіну

Гарний приклад для показу гнучкості системи - не тільки повні кімнати, а й окремі зони.
